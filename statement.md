Statement - Python Utility for Number Guessing Game

1. Problem Statement

Guessing a number manually is an interesting game.
This project creates a python-based Number Guessing Game in which , computer chooses a random number between 1 and 100 and the user attempts to guess it.
The program provides hints such as a "high" or " low" after each guess. The game also counts the number of attempts and prints the final result.

2. Scope of the Project

The project is designed as a simple python game for learning programming concepts.
The project includes:
Generating a random number.
Taking the user's guess.
Checking the guess.
Giving hints to the user.
Counting attempts.
Displaying the final result.
Allowing the user to play again.

3. Target Users

The target users are:
Students learning Python.
Beginners who want to practice programming.
Users who want to play a simple number guessing game.

4. High Level Features

The main functions of the project are:
Random number generation.
User input for guessing the number.
Checking whether the guess is correct.
" high" and "low" hints.
Attempt counting.
Win or lose result.
Play-again option.
Modular Python files for different parts of the program.
